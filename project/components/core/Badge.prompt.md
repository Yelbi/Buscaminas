Compact status pill — game state, player turn, difficulty, online/offline.

```jsx
<Badge tone="lime" dot>En línea</Badge>
<Badge tone="magenta" solid>VERSUS</Badge>
<Badge tone="yellow">Difícil</Badge>
```

`tone` sets the hue; `solid` fills it; `dot` adds a glowing status dot. Text is uppercase pixel display font.
