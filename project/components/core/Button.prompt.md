Neon action button — use for any primary/secondary CTA, menu actions, and dialog confirms.

```jsx
<Button variant="primary" size="lg" onClick={start}>Jugar</Button>
<Button variant="secondary">Invitar amigo</Button>
<Button variant="ghost" size="sm">Cancelar</Button>
```

Variants: `primary` (cyan), `secondary` (magenta), `win` (lime), `danger` (red), `ghost` (outline). Sizes: `sm` `md` `lg`. Use `block` for full-width, `iconLeft`/`iconRight` for glyphs. Label text uses the pixel display font.
